# Amazon-Sales-Analysis

Amazon Sales Analysis Dashboard

This project presents an interactive Amazon Sales Analysis Dashboard built in Microsoft Excel. The dashboard analyzes nearly 40,000 sales transactions and provides insights into revenue, order trends, product performance, customer behavior, and regional sales distribution.

**Key Features**
Data cleaning and transformation using Excel and Power Query
Interactive dashboard with slicers and filters
Sales and revenue trend analysis
Category and product performance tracking
Customer and geographic sales insights
KPI monitoring for business performance

**Tools Used**
Microsoft Excel
Pivot Tables & Pivot Charts
Power Query
Data Visualization
Dashboard Design
